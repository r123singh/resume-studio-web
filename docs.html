Quickstart

Docs

1. Install

Download for Windows, extract, run Resume Studio.exe.

2. Add an API key

Open Settings. Choose OpenAI, Anthropic, or Gemini. Paste your key. Keys are stored encrypted on your machine via Electron safeStorage.

3. Open a workspace

Click Open workspace folder. Resume Studio creates base-resume.md and resumes/ if missing. Paste your master resume into base-resume.md and save (Ctrl+S).

4. Tailor from a JD

In the AI panel, open Tailor from JD. Enter company + role, paste the job description, generate. A file lands at resumes/company--role.md.

5. Refine and export

Use Edit open file chat for tweaks. Click Export PDF for ATS upload. You apply manually — Resume Studio never submits applications.

Tips

  • Never invent employers or metrics — the model is instructed to use only base-resume facts.
  • You can point the app at an existing job-automation folder.
  • If Windows SmartScreen warns, choose More info → Run anyway (unsigned build).
